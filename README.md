# Gesture & Voice Controlled PowerPoint Presentation 🎤✋  

This project allows you to control a PowerPoint presentation using **hand gestures** and **voice commands**. It uses **computer vision** to detect hand gestures via a webcam and **speech recognition** for voice commands.

## 🚀 Features  
✔️ **Hand Gesture Control** (Next/Previous Slide)  
✔️ **Voice Control** (Start, Next, Previous, Stop, Close Presentation)  
✔️ **Real-time Webcam Feed**  
✔️ **Smooth Integration with Microsoft PowerPoint**  

## 📌 Prerequisites  
- Python 3.7+
- Webcam
- Microsoft PowerPoint (Installed)  

## 🛠️ Installation  

### **1. Clone the Repository**  
```sh
git clone https://github.com/your-repo/gesture-voice-ppt-control.git
cd gesture-voice-ppt-control
```

### **2. Install Dependencies**  
Ensure you have Python **3.7 or later** installed, then run:  
```sh
pip install -r requirements.txt
```

### **3. Run the Program**  
```sh
python app.py
```

## 🖐️ Hand Gesture Controls  
| Gesture | Action |
|---------|--------|
| ✋ Open Palm | Next Slide |
| 👍 Thumbs Up | Previous Slide |
| ✌️ Shape with Fingers | Activate Voice Control |

## 🎤 Voice Commands  
| Command | Action |
|---------|--------|
| "Start" | Begin Slideshow |
| "Next" | Move to Next Slide |
| "Previous" | Move to Previous Slide |
| "Stop" | Stop Slideshow |
| "Close" | Exit PowerPoint |

## Troubleshooting
- If the camera feed doesn't show, check your webcam permissions.
- If voice recognition isn't working, ensure your microphone is enabled and properly set up.
- If PowerPoint doesn’t open, verify the `ppt_path` is correct.
